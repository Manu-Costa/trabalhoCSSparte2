Sobre o Trabalho

Uma recriação da plataforma Netflix para um trabalho de Linguagens para Internet I.

O Projeto

Este site é uma cópia da Netflix desenvolvido como um trabalho. O objetivo é praticar HTML, CSS e organização de páginas web.

Tecnologias

Utilizamos HTML5 para estrutura, CSS para estilização e organização do visual.

Design

Inspirado na interface da Netflix, com foco em layout escuro, cards e navegação simples.

Integrantes

Rafael Silvio: Filmes, Series, Lançamentos, Top10 e Categorias
Manuella: Index(início), Contato e Sobre.
Mariana: Login, Cadastro, Debito, Credito e Perfil
